New in v2.22: set up each agent once

  1. Extract the ZIP to a stable approved folder. Keep index.html at the same path for subsequent calls. Use the same normal browser profile; private browsing is not suitable for retention.
  2. Open index.html. In Knowledge, select the exported JSON and exact matching PDF.
  3. Scroll to Remember on this device and select Remember current release on this device. Wait for the saved confirmation. This stores a local browser copy of the pair; it does not publish anything.
  4. Close the tab, then reopen the same file. Confirm the saved release restores and an article's PDF opens without selecting files again.
  5. Launch that same address with a configured intent parameter, for example ?intent=escrow_help when using sample-intent-knowledge.json. FlightDeck restores the saved pair before routing. Try several calls.
  6. Repeat setup separately for each agent/browser profile. If company policy blocks storage or the browser clears its data, load the files again. Persistence is not guaranteed by this demo.

To update the manual, choose Replace saved manual, load the replacement JSON and matching PDF, then remember the new pair. The prior saved pair remains until the replacement is validated and committed. Exports and Admin changes do not automatically update every agent.

Forget this device’s copy removes its saved pair and favorites. The already-loaded session and original files remain available. Reset loaded knowledge only clears the session; use Forget to remove the saved browser copy. Other open tabs may still hold their own loaded copy; close them if needed. Moving/renaming index.html creates a different storage location; forget the old location first if you want its stored copy removed.

Quick answers and Favorites

The five shared category tiles keep their familiar order. Shortcut rows use larger text and state Open procedure or the number of article choices. Tile totals are removed; sidebar totals count available articles consistently.

  1. Open a procedure and choose ☆ Add to favorites. Return to Quick answers to see it above the tiles.
  2. Click a favorite to open it, hover to preview, or select Remove to unpin it. Up to 30 favorites are supported.
  3. Favorites are personal to this browser. They persist only when a device release is saved. If a replacement pack no longer includes a favorite, it is labeled unavailable rather than opening a different article.

Expanded preview controls

Previews now open at approximately 800px wide (smaller on narrow screens), use up to 85% of browser height, and open toward the content area. The PDF scrolls within the popup. Single-page articles omit Previous/Next.

Choose Fit width, 125%, or 150% to enlarge the actual PDF. Pin preview keeps it open when the pointer leaves; Unpin restores hover behavior. Close preview, Escape, opening the article, or entering Knowledge/Admin closes it. A new pack also closes it. Home shortcuts and favorites support previews; grouped shortcuts let you pick an article first.

Test original-PDF preview popups

  1. Open an article and hover for about half a second over another article in the right pane. A popup shows the original PDF page without changing the main reader.
  2. Move the pointer into the popup to keep it open. Use Previous / Next for a multipage article. Open article changes the main reader; Close preview or Escape dismisses the popup.
  3. Try the left navigation. If a customer-need label represents several articles, the popup first lets you choose which article to preview.
  4. Try keyboard focus on an article link and the PDF previews: on/off button in the top bar. Clicking a normal article link still opens it immediately. Touch users can continue opening articles normally.
  5. Try long headings, dark theme, your normal browser zoom and smaller window sizes. The preview is an image of the original page; links inside this preview image are not interactive. Open the article to use the main reader's links and zoom.

Optional Admin description: select an article and find Article preview under Navigation & Placement. Add a short “Use this when…” description and check that you reviewed it. Unchecked descriptions are hidden. The actual PDF preview works with no description. Source changes clear the description's review flag.

Configure intents without editing code

  1. Open Admin using the existing demo entry. In the outer Admin bar, select Edit current pack intent routes to bring your loaded pack into the editor. If you have unsaved Admin work, save it first. Alternatively, choose a pack as the previous file in Admin, then Edit loaded knowledge pack — no PDF needed.
  2. Select Manage intent routes. Existing routes and missing/unavailable destination warnings are listed. Search for a route or choose Add intent route.
  3. Enter a name, incoming parameter and matching values, one per line. Parameters are intent, OBCampaignName and IBUtterance. Exact matching normalizes capitalization, punctuation, hyphens/underscores and whitespace.
  4. For IBUtterance only, you may choose Contains whole phrase. This is literal matching, not language understanding: “do not make a payment” can still contain “make a payment.” Prefer specific exact aliases or structured intent codes when available.
  5. Search the article catalog and click + to link several articles. Link all matching articles adds the filtered set. Earlier / Later sets their order; Unlink removes only that route connection.
  6. Choose Show article choices or Open primary article. For primary mode, select Set primary on the desired article. Keep other relevant articles linked as one-click choices.
  7. Select Save route. Route changes are saved in the current Admin workspace, not automatically published. Use the tester below to enter one or several incoming values. It tests saved routes; an unfinished editor is excluded.
  8. Use Export demo knowledge pack / Use demo pack in AgentOS if the release contains demo acceptance or pending review; use the reviewed-pack actions for a fully reviewed release. Save review draft retains unfinished overall review work. Save the open route editor before exporting or saving a draft.
  9. Reload the exported pack in Knowledge and attach its exact PDF. Reopen Admin to confirm the routes, article order and primary selection persisted.

Manual Articles now controls source headings, page boundaries and inclusion. Navigation & Placement controls browsing labels and groups. Intent Routing is the single editor for incoming-call connections. Existing topic IDs remain internally for compatibility; the duplicate input controls have been removed. Each article shows “Used by these intents.”
