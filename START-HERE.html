AgentOS v2.17 test notes

This build adds review recovery and more conservative PDF change detection. These notes support your review period; the full Admin Guide will follow after the demo build is agreed.

Open AgentOS v2.17 · Open the standalone importer

Start with your existing files

  1. Keep a backup of your current index.html and exported JSON. Put the new index.html in your local test folder and open it. Confirm the page shows v2.17.
  2. Open Knowledge. Select your existing exported JSON and its matching PDF. Existing knowledge packs still load; no reimport is needed to test navigation or the PDF reader.
  3. To establish the new visual comparison baseline, open Admin, select that JSON under Previous PDF or exported knowledge pack, and select the exact same PDF under Revised PDF. Select Read / compare PDFs.
  4. Reviews are retained when the existing pack identifies the exact same PDF and the section boundaries are unchanged. Resolve any flagged subject, enter a new release label and reviewer, then Export reviewed knowledge pack. Keep this JSON for your next manual update.

Test review preservation and recovery

  1. Import one of the fictional sample PDFs. Approve a procedure, then type an optional answer on another procedure without approving it.
  2. Add an alias or another subject mapping. The approved procedure and unfinished answer should remain when their source text and boundaries are unchanged. If a newly detected heading changes a section boundary, that section correctly needs review again.
  3. Select Save review draft. Confirm the JSON download completed. A draft saves pending decisions, answers, unfinished formatting, manual ranges, navigation labels and relationships.
  4. Close and reopen the importer. Expand Save or resume review work, select Resume a saved draft, and choose the draft JSON. Select Attach the matching PDF after resuming and choose the original PDF. Continue the pending review; do not run a comparison simply to resume.
  5. Try attaching a different PDF. It should be rejected while retaining your draft.
  6. Filter Show subjects to Needs review, search by heading or ID, and use Next needs review. Use Remove from this release for an accidental mapping; its saved relationships are also removed.
  7. Try an invalid PDF or cancel a new read. Previous review work should remain. Reloading or locking an unsaved importer should request confirmation; browser close behavior can vary, so save the draft first.

Save review draft is for continuing Admin work. Export reviewed knowledge pack creates the agent release after all selected subjects have a decision. Use reviewed pack in AgentOS applies it only in the current tab and does not download a backup.

Test a graphic change with identical text

Use these fictional PDFs: Visual sample A and Visual sample B. Only the colored rectangle on the escrow statement page changes.

  1. Start with no previous file selected. Import visual sample A, review the eight starter procedures and export a reviewed pack.
  2. Select that newly exported JSON as the previous pack, and visual sample B as the revised PDF. Read / compare.
  3. ESC-001 should be flagged visual-change even though the extracted text is the same. Other unchanged procedures should retain their reviews.
  4. Open the original page and review the graphic change. Approve the subject. If you had a reviewed relationship involving that source, review the relationship again before expecting it to appear to agents.

Page images are checked at up to 72 dpi to flag possible changes. This is a review aid and does not guarantee detection of every small detail. Headers, footers and printed page numbers can also trigger a flag. If image comparison fails or an older baseline has no comparable page images, the subject is flagged visual-review instead of being treated as verified unchanged.

What to watch during your review

  • Keep your familiar main groups, icons, six common needs, search, original-PDF reader and reviewed related-article links in the demo.
  • Review drafts and knowledge packs contain manual text. Local file selection and these new comparison features add no network service. Original PDF bytes are not embedded in a saved draft or knowledge JSON.
  • Large manuals now include a page-image pass, which adds processing time. The importer still requires selectable text and does not provide OCR. File limits remain 150 MB for PDFs and 30 MB for agent knowledge packs; review drafts have a 150 MB limit.
  • A synthetic 800-page manual with 573 selected mappings completed text extraction, page-image hashing and draft validation in testing. Those were simple generated pages; your real manual and work VM still need their own timing and usability check.
  • Automated checks used actual PDF rendering with simulated interface events. Your work-browser testing remains the check for layout, interactions and local environment behavior.

For feedback, record the procedure ID, action taken, expected result and actual result. Keep the relevant draft and exact PDF so the workflow can be repeated locally.
